# Third-party notices

TSWriter by Jon Becker, with Codex, 2026. Uses GEOS and other fonts.

- GEOS bitmap faces originate with Berkeley Softworks. Pinned strikes and source
  identifiers are in `fonts/sources/` and `fonts/geos-catalog.json`.
- Liberation: SIL Open Font License, `fonts/OFL-Liberation.txt`.
- DejaVu: `fonts/desktop-sources/LICENSE-DejaVu.txt`.
- Twobit: Neale Davidson / Pixel Sagas; original `PS_Twobit.zip` retained in
  `fonts/desktop-sources/`, with notices in the desktop package.
- UnifrakturMaguntia and other outline sources retain notices in
  `fonts/desktop-sources/` and the desktop package's `Licenses/` directory.
- SirClive: Paul Reid; `fonts/SirClive-README.txt` and the original
  `fonts/sources/sirclive_ttf.zip`, also retained in the desktop font package.
- Timex/Sinclair system character design is separately credited in the desktop
  package. Its pixel-shaped transcription is not covered by the other fonts'
  OFL licenses. No complete system ROM is included.

The desktop package manifest identifies each font's source, family name and
matching limitations. Keep the notices with the fonts. No blanket project license
supersedes these third-party terms.
