RTF into TSWriter

Prepare a desktop RTF for TSWriter and package it into a .tap file. The TS2068 converts the prepared RTF into its native document format.

  1. Choose an RTF below, review the reported changes, and download the import TAP.
  2. In Fuse, turn off Options > Media > Auto-load media, then open the TAP using Media > Tape > Open.
  3. In TSWriter, choose File > Import RTF. Save your current document first: import replaces it.
  4. Press Enter. Use Fuse's Tape > Play (F8) if tape traps are disabled.
  5. The editor returns automatically when loading finishes. Use File > Save to tape to keep the native document.

Removes running headers/footers and document metadata; changes curly quotes, dashes and accented Latin letters to plain equivalents; keeps a field's stored displayed text. Body formatting and picture groups are retained. Uncheck to package the original bytes unchanged. Your original file is never overwritten.
